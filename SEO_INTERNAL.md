# SEO: текущее устройство

- Индексируемые статические страницы перечислены в scripts/routes.mjs.
- npm run build обязательно пререндерит их и проверяет конечный HTML через check-seo.mjs.
- Seo.jsx обновляет метаданные через DOM, без react-helmet. Production origin по умолчанию carpasss.ru.
- Главная, owners, business, города и блог получают собственные canonical и JSON-LD.
- Кабинеты и приватная история share закрыты от индексации. Nginx добавляет серверный X-Robots-Tag.
- Публичные страницы партнёров /d/:id динамические: пока без SSR и без sitemap.
  Их серверный рендер и динамическая карта сайта требуют отдельного развития.
- Городские страницы требуют местных кейсов и фактических данных партнёров; замена города не создаёт уникальную ценность.
- Метрика подключена в index.html; цели — src/lib/metrika.js. Webvisor выключен.
  CookieBanner пока только уведомляет: не управляет загрузкой счётчика.
- Права в Search Console/Вебмастере и статус индексации проверяются в соответствующих аккаунтах.

Порядок выкладки и проверки сервера: DEPLOY.md. Не считать наличие nginx-конфига
в Git подтверждением его применения на production.
