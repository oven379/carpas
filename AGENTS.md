# Команда КарПаса

Когда пользователь поручает команде интерфейсную задачу, ведущий агент распределяет её по ролям.

1. `carpas_ux_designer` описывает путь пользователя, текст, состояния и критерии приёмки. `carpas_ui_designer` уточняет внешний вид и адаптацию. Они могут работать параллельно и передают ведущему агенту единое решение.
2. `carpas_frontend` получает решение с указанием экранов и файлов, реализует его и сообщает о проверках. Подключай `carpas_integrations`, когда затронуты API, авторизация, сессии или обмен данными с мобильным приложением.
3. `carpas_qa` получает итоговые критерии и проверяет реализацию через пользовательские точки входа. Для найденного дефекта указывает шаги воспроизведения, ожидаемое и фактическое поведение.

Для передачи работы достаточно описать цель, решение, ограничения и признаки готовности. Ведущий агент объединяет результаты и разрешает расхождения. У каждого изменяемого файла один исполнитель одновременно.
